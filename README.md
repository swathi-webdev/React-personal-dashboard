# React Personal Dashboard

A modern, responsive personal dashboard built with React and Vite.  
Track your tasks, view productivity stats, and manage priorities.

## Features
- Add, delete, and toggle tasks
- View completed, pending, and recent tasks
- Productivity statistics
- Responsive design

## Technologies
- React + Vite
- Bootstrap 5
- LocalStorage for persistent tasks

## How to Run
1. Clone the repo: `git clone https://github.com/swathi/React-personal.git`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
